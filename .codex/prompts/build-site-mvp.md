# Codex Prompt: Build Site MVP

このリポジトリで津和野PRサイトの MVP を作るときは、次の指示で進めてください。

1. 最初に `AGENTS.md` と `project-brief.md` を読む。
2. `project-brief.md` の ①②⑤⑥⑦⑧⑨⑩⑪ を、どの UI 要素に使うか短く整理する。
3. `web/` が無ければ、Next.js / React の最小構成を作る。
4. トップページには少なくとも次を含める。
   - ⑪の第一声をヒーロー見出しに置く
   - ②の 15 秒説明をリード文に使う
   - ③⑤⑨を使った魅力紹介を 3 つ程度入れる
   - ⑦の気持ちを締めの一文に使う
5. ⑧の声のトーンに合わせて余白・配色・文体を整える。
6. ⑩の禁止事項に触れていないか、最後に自己チェックする。
7. 可能なら `cd web && npm run build` を実行し、結果を報告する。

注意:

- 実写素材が無ければプレースホルダで進める。
- まずは 1 ページの MVP を成立させ、必要以上に機能を広げない。
- `project-brief.md` と矛盾するコピーは作らない。
